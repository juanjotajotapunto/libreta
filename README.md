# Libreta de Cuentas

App privada para controlar ingresos, gastos y saldos de varias cuentas bancarias.

- Se instala como app en Android, Windows y Linux (Brave, Chrome, Edge o Chromium).
- Funciona sin conexión.
- Los datos se guardan **cifrados con tu contraseña** (AES-256-GCM, clave derivada con PBKDF2 de 600.000 iteraciones) en el dispositivo.
- La sincronización entre dispositivos usa un Gist **secreto** de tu cuenta de GitHub, que solo contiene datos cifrados.
- Este repositorio solo contiene el código: **no hay ningún dato tuyo aquí**.
